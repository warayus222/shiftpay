# ตารางเวร (Shift Pay Tracker)

เว็บแอปบันทึกเวรและสรุปรายได้รายเดือนสำหรับพยาบาล — ค่าเวรดึงจากตารางเรทอัตโนมัติ มีสรุปรายเดือน ปฏิทินเวร กราฟรายได้รายวัน และสรุปทุกเดือนทั้งปี

## ฟีเจอร์
- **สรุปเดือน** รายได้รวม สัดส่วนรายได้ จำนวนเวรตามประเภท ปฏิทินเวร กราฟรายวัน
- **บันทึกเวร** เลือกประเภทวัน (วันธรรมดา / OT / OFF) และเวร ค่าเวรคำนวณให้เอง รองรับหลายเวรต่อวัน ชั่วโมงเสริม Refer / Oncall / รายได้อื่นๆ
- **ทุกเดือน** เทียบรายได้รายเดือนทั้งปี
- **ตั้งค่าเรท** แก้เรทเวร เรทชั่วโมงเสริม Refer และ Oncall ได้เอง
- **โหมดกลางวัน/กลางคืน** ปุ่มที่มุมขวาบน จำค่าที่เลือกไว้ (ถ้ายังไม่เลือกจะตามการตั้งค่าของเครื่อง)
- **ติดตั้งเป็นแอป (PWA)** ใช้ออฟไลน์ได้ ข้อมูลเก็บในเบราว์เซอร์ของเครื่อง พร้อมปุ่มส่งออก/นำเข้าไฟล์สำรอง

## ใช้งาน
เปิด `index.html` ผ่านเว็บเซิร์ฟเวอร์ใดก็ได้ เช่น

```bash
python3 -m http.server 8000   # แล้วเปิด http://localhost:8000
```

หรือเปิดใช้ GitHub Pages (Settings → Pages → Deploy from branch → `main` / root) แล้วเปิดลิงก์บนมือถือ
เลือก "เพิ่มลงหน้าจอหลัก" (iOS Safari) หรือ "ติดตั้งแอป" (Chrome/Android) เพื่อใช้เหมือนแอป

> ข้อมูลที่กรอกเก็บใน `localStorage` ของเบราว์เซอร์นั้นเท่านั้น ถ้าล้างข้อมูลเบราว์เซอร์หรือเปลี่ยนเครื่องข้อมูลจะหาย
> ให้ใช้ **ตั้งค่าเรท → สำรองข้อมูล → ส่งออกไฟล์สำรอง** เป็นระยะ

## โครงสร้าง
| ไฟล์ | หน้าที่ |
|---|---|
| `src/page.html` | ซอร์สหลักของแอป (HTML + CSS + JS ไฟล์เดียว) |
| `scripts/build.py` | ห่อ `src/page.html` เป็นเอกสารเต็ม → `index.html` |
| `index.html` | ไฟล์ที่ผ่านการ build แล้ว (เสิร์ฟไฟล์นี้) |
| `manifest.webmanifest`, `sw.js`, `icons/` | ส่วนของ PWA |

แก้ซอร์สที่ `src/page.html` แล้วรัน `python3 scripts/build.py` ใหม่ทุกครั้ง

## การคำนวณ
ค่าเวรของแต่ละรายการ = เรท[เวร, ประเภทวัน] (OFF = 0) + ชั่วโมงเสริม × เรทชั่วโมงเสริม
รายได้รวมเดือน = ค่าเวรทั้งหมด + ชั่วโมงเสริม + Refer (จำนวน × เรท) + Oncall (จำนวน × เรท) + รายได้อื่นๆ

เรทตั้งต้นในแอปเป็นค่าตัวอย่าง แก้ได้ที่แท็บ "ตั้งค่าเรท"
